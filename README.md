# 📊 PhonePe Digital Payments Case Study

*(Analyzing Transaction and Demographic Data using Python)*

---

## 📝 Overview
This project is a **data analysis case study on PhonePe digital payments**, focusing on transaction trends and demographic patterns across **Indian states and districts**.

Using Python, the study explores:
- Growth and patterns in digital transactions
- User adoption across regions
- Demographic correlations with transaction behavior
- Data consistency and advanced analytical insights through visualizations

The analysis is performed across **multiple years and quarters**, giving a comprehensive view of how digital payments have evolved in India.

---

## 🎯 Objectives
- Analyze transaction trends over time
- Understand regional differences in digital payment usage
- Study user behavior through registered users and app opens
- Explore relationships between population, density, and transactions
- Create meaningful visualizations for business insights

---

## 📂 Dataset Description
The dataset is provided in an **Excel file with multiple sheets**, each representing a different aspect of PhonePe’s transaction and demographic data.

### 🔹 State-Level Datasets

#### 1. State_Txn_and_Users
Contains transaction and user data at the state level:
- Number of transactions
- Total transaction amount
- Average transaction value (ATV)
- Registered users
- App opens

#### 2. State_TxnSplit
Breakdown of transactions by type at the state level:
- Transaction type
- Number of transactions per type
- Total transaction amount
- Average transaction value per type

#### 3. State_DeviceData
Device usage statistics of registered users at the state level:
- Device brand
- Number of registered users
- Percentage share of each device brand

---

### 🔹 District-Level Datasets

#### 4. District_Txn_and_Users
Transaction and user data at the district level:
- Number of transactions
- Total transaction amount
- Average transaction value
- Registered users
- App opens

#### 5. District_Demographics
Demographic information for each district:
- Population
- Area
- Population density
- District headquarters

## 🛠️ Tools & Technologies Used
- Python 🐍
- Pandas – Data manipulation and analysis
- NumPy – Numerical computations
- Matplotlib  – Data visualization

---

## 📈 Key Analysis Performed
- Year-wise and quarter-wise transaction trends
- State and district-level comparison of transactions and users
- Correlation analysis between demographic and transaction variables

- Visualization of growth patterns and regional insights
